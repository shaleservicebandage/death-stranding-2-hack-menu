## 🧩 About

**Death Stranding 2 Companion** is a curated list of Death Stranding 2 open-source tools:

- **Overlays** — on-screen helpers, layout notes, route viewer, cargo tracker
- **Quality-of-Life Helpers** — delivery catalog, loadout manager, overlay notes
- **Research Notes** — traversal layouts and config notes for educational use

Based on publicly available community tools and overlay helpers.

---

## ✨ Features

### ESP
- Route Planner — practice from any waypoint
- Cargo Overlay — visualize load and weight
- Replay Notes — record and review delivery runs
- Playback Speed — adjust map playback for study (0.1x to 5x)

### Wallhack
- Gear Catalog — browse gear, colors, and upgrades
- Custom Loadout Notes — organize equipment cosmetics
- Terrain Highlight — improved route visibility

### Aimbot
- Practice Mode Notes — segment study on any route
- Balance Control — manually test balance states
- Stamina Buffer Notes — chain complex maneuvers in the field
